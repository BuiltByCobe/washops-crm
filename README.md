# WashOps CRM

WashOps is a lightweight CRM scaffold for pressure washing and exterior cleaning businesses.

Quick summary
- Simple customer/workflow focus for estimates, rates, and job-level profit checks.
- Mobile-friendly, static prototype (no server required).

Quick start
- Open index.html in your browser, or serve locally:
  python3 -m http.server 8000
  Visit: http://localhost:8000

Repository layout
- index.html — static prototype UI and logic
- README.md, LICENSE.md, CONTRIBUTING.md, SECURITY.md, CHANGELOG.md
- .env.example — local environment placeholders
